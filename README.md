# Marketing budget optimisation

How should a group with three acquired businesses spend a fixed **$2M paid-acquisition budget** to maximise
long-term contribution profit, without taking on excessive acquisition or concentration risk?

This project forecasts marketing performance, designs and analyses experiments, and builds a constrained
budget optimiser that uses diminishing returns and uncertainty. It then turns the results into a decision
memo for a CEO, CFO and Marketing Director.

**Status:** phase 0 of 9 is complete: scope, business case, metric definitions and the design of the
simulated world. See [docs/phase_plan.md](docs/phase_plan.md).

> **The data are simulated.** A simulation is the only way to know each channel's true effect, and therefore
> to check that the analysis separates real impact from what ad platforms report (D-001). Results show that
> the method works. They are not findings about a real company.

## The question in one table

At last year's spend, the simulated company's dashboards and its real economics disagree. This is the
starting point the analysis has to diagnose from the data alone; models never see this table.
(`reports/ground_truth_summary_SYNTHETIC.md`, generated by `uv run mbo design`.)

| | Platform-reported return | What the next dollar earns |
|---|---|---|
| B1 brand search | 2.11 | 0.36 |
| B3 retargeting | 1.28 | 0.15 |
| B3 social prospecting | 1.42 | 1.46 |
| B2 LinkedIn | 2.22 | 1.55 |

Return = 24-month contribution per advertising dollar; above 1.0 the spend pays for itself.

## How to run

Requires [uv](https://docs.astral.sh/uv/) (Python 3.11 is installed automatically).

```bash
uv sync
uv run mbo all       # every pipeline step (phase 0: the design check)
uv run pytest        # tests
uv run ruff check . && uv run mypy src
```

## Stack

Python 3.11, pandas, NumPy, SciPy, statsmodels and scikit-learn (from phase 2), DuckDB SQL, Tableau Public.
LLM-assisted reporting arrives in phase 7, with a template fallback.
